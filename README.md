I'm a software developer working primarily with **TypeScript, Java and Kotlin**. I build web applications, backend services, APIs, and systems that need to do more than just work on the happy path.

I enjoy exploring the engineering decisions behind software: how applications are structured, how data moves through a system, how authentication and security work, and how to build reliable features without making the codebase unnecessarily complicated.

I'm also interested in control systems, embedded development, and the space between hardware and software. My background in mechanical engineering continues to shape how I approach technical problems.

Outside of coding, I enjoy reading fiction and non-fiction, singing, and dancing.

### Things I enjoy exploring

- **Backend engineering:** API design, authentication, authorization, data integrity, and reliable background processing.
- **System design:** architecture, event-driven systems, multi-tenancy, and the trade-offs behind engineering decisions.
- **Frontend and mobile:** building practical interfaces and applications that solve real problems.
- **Embedded systems and control:** experimenting with Arduino, electronics, instrumentation, and the relationship between physical systems and software.

I also write about what I learn, from debugging and architecture decisions to the small details that make software easier to maintain.
